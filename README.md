# 💖 Ray - Um Presente Digital

Este projeto é uma pequena homenagem criada para minha namorada. Trata-se de um site simples, mas cheio de carinho, que conta o tempo que estamos juntos e celebra nosso amor com uma animação especial 💫.

🛠️ **Tecnologias usadas:**
- HTML5
- CSS3
- JavaScript puro

📅 **Funcionalidade principal:**
- Um contador que mostra o número de dias, horas, minutos e segundos desde o dia 06 de março de 2024.
- Todo dia **6 de qualquer mês**, confetes e corações caem pela página como forma de celebração ✨.

🌐 **Acesse o site ao vivo:**  
🔗 [https://xoxoo.shop](https://xoxoo.shop)

📁 **Estrutura do projeto:**
```
ray/
├── assets/
│   ├── js/
│   │   └── script.js          # Lógica do contador e animação
│   ├── style/
│   │   └── styleTimer.css     # Estilo do site
│   └── imags/
│       └── icon.ico           # Ícone do site
├── index.html                 # Página principal
```

🎉 **Destaques:**
- Interface responsiva e leve
- Animação personalizada com emojis de coração e confete
- Projeto feito com amor ❤️
